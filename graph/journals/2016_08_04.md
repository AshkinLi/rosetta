	- 简介
	  heading:: true
		- Plantoids Species Pack 为玩家带来了全新的样貌，伴随独特的特性和民政、全新船舰，以及一系列全新的玩家肖像与城市景观艺术图。Plantoid 给予玩家扮演类植物物种的机会，这个物种已发展出知觉，并开始将卷须伸展到星系的各个角落，在新的星球上种下新文明的根。从允许种族数量成长的全新物种特性，到改造盖亚世界所需的向光资源，玩家可以悉心栽培自己的帝国，并以全新方式向外扩张。
	- 内容
	  heading:: true
		- 全新民政
		- 全新物种特性
		- 全新物种肖像
		- 全新植物类（Plantoid）船舰模板
		- 全新城市景观艺术图
	- 更新 (2021)
	  heading:: true
		- 从 Stellaris 的 3.1 更新版开始，Plantoids Species Pack 的内容确实更加丰富了，如今包含了 Plantoids 的专属特性与民政。玩家现在可以选择让其市民成为向光性或放射性；可以利用“Idyllic Bloom”民政将星球改造为盖亚世界，或者通过“Catalytic Processing”民政把食物变为合金。
